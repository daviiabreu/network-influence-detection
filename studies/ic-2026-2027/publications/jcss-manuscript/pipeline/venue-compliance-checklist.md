# Venue compliance checklist

Apply this to the selected venue and exact submission package. The [source notes](venue-source-notes.md) give the official URLs, section locators, short quotations and qualifications for every rule. Checked 2026-09-27; recheck the pages at submission. Each box remains open until verified against the final PDF and accompanying files.

| Item | JCSS primary | JASSS alternative |
| --- | --- | --- |
| Length | [ ] Record PDF words/pages; no numeric cap in [official guidelines](https://link.springer.com/journal/42001/submission-guidelines); justify unusual length. | [ ] Record body words/pages; [official instructions](https://www.jasss.org/v02/page_content_includes/_include_submit.html) say typically 5,000–8,000 words plus attachments, no page cap. |
| Structure | [ ] Title page, clear sections with at most three numbered levels, editable source and PDF; Springer `[iicol]` recommended. | [ ] Five or six headed sections without author-added section numbers; main file and preferably anonymised PDF. |
| Abstract | [ ] 150–250 words, no undefined acronyms or unspecified references. | [ ] Use 200–300 words under detailed section; opening sets only 300-word ceiling. Recheck conflict. |
| Keywords | [ ] Four to six. | [ ] Use three to six under detailed section; opening gives only six-keyword ceiling. Recheck conflict. |
| Data and code | [ ] Data availability/access restrictions stated; material/code availability when relevant; replication detail and exact source package. | [ ] Enough detail for replication; code/documentation sharing and CoMSES deposit are recommended, not universal requirements. |
| LLM use | [ ] Substantive generative use documented in Methods; no LLM author; humans accept responsibility. | [ ] Disclose use transparently; no specific LLM rule found on consulted submission page. |
| Ethics/declarations | [ ] Funding, competing interests, contributions, ethics/consent applicability, permissions and originality checked. | [ ] Originality and no duplicate submission; assess applicable ethics, conflicts and funding under current policy. |
| Figures/tables | [ ] Sequential citations and numbered captions; legible electronic figures, permissions and accessibility checked. | [ ] Figures in place and separately supplied, caption outside image; check width and reviewer PDF rendering. |
| References | [ ] Numbered square-bracket citations/list; cited works only; DOI URL when available. | [ ] Modified APA author–date citations without comma; alphabetical list. |
| Supplement | [ ] Cited files, consecutive names and captions, standard formats; review the supplied files as final. | [ ] Essential content in reviewer PDF: referees receive paper PDF, not separate supplement files. |
| Model documentation | [ ] If ABM, ensure sufficient model detail for replication. | [ ] ODD recommended, not required; use the [2020 ODD template](review/odd-2020-template.md) for this project. |

The source notes distinguish journal rules from project choices. The current draft has unresolved placeholders, unvalidated results, pending human scientific decisions and venue-specific conversion work, so no row is signed off merely because the mechanical checker runs.
