## Method

- **Scope.** Every `% ID` marker in `main.tex`, `sections/*.tex` and `generated/*.tex` was listed. There are 238 distinct IDs, each with one active ledger row. The integration log (section 7) says 237, so its count is one short. Retired rows (C08–C15, A03, C20, C21, C24–C30, A05, C42–C46, A08, R01–R22 and VER05), the superseded V rows and the MAP rows have no marker and were skipped.
- **Code evidence.** Each cited function was read at the cited lines. `git diff 37513841 HEAD -- src/` only adds files, so every cited code file equals its frozen bytes. The model code was not executed, because the environment has no NumPy. Derivations were recomputed in pure Python.
- **Document evidence.** Each passage was read at its cited lines, in Portuguese where the source is Portuguese.
- **Numbers.** Hashes were recomputed with `sha256sum`:
  - v1 protocol at `fd65d2a`: `fb6b4dcf…d706` ✓.
  - `freeze-v4.json` at `37513841` and at HEAD: `99c42772…0837` ✓.
  - The six protocol files, `criteria-v43.json` and `inventory.json` all match `freeze-v4.json` ✓.
  - The printed code-closure hash is wrong; see ODD01.
- **Web and private sources** were not accessed; those rows are X.
- **Division of work.** Seven read-only sub-audits ran in parallel, one per row group. The following findings were re-checked by hand: ODD01, M04, M18, M27, M49, M54, M61/M62, R24, R56, AV01, AV05/AV10, DS03, DS10/ODD39 and the supplement's zero-variance sentence.

**Classes.**
- **S:** the evidence at the locator states the claim at the same strength.
- **O:** the sentence is stronger than the evidence.
- **U-l:** the locator does not resolve or does not state the claim, but another repository file supports it. A ledger correction is given.
- **U-n:** no repository file supports the sentence as written.
- **X:** the evidence is external or private.
