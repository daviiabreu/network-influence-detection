# IC 2026–2027

This README preserves the initial study-discovery status below. The independent
extraction and its current publication entry points are described in the
[repository README](../../README.md); no scientific execution or acceptance was
added by extraction.

Research compendium and scientific implementation for the IC. Opinion dynamics
is the initial discovery area; no final question, hypothesis, model, method, or
target venue has been approved.

The previous proposal and repository may later enter the literature process as
historical inputs. They are not authoritative requirements for this study.

## Ownership

- `src/ic_study/`: reusable scientific implementation;
- `tests/`: computational and scientific verification;
- `research/`: protocols, searches, evidence, synthesis, and decisions;
- `experiments/`: exploratory and registered experiment specifications;
- `publications/`: claim-evidence maps and submission packages;
- `notebooks/`: disposable exploration that calls code from `src/`;
- `data/manifests/`: tracked descriptions and hashes for externally stored data.

## Current state

The [provenance guide](../../docs/reproducibility.md)
links the broad acquisition, corpus/calibration dependencies, venue evidence,
implementation specifications and verified results. The approved protocol and
completed acquisition are distinct from a completed systematic review.

Scientific implementations and two exploratory pilots already exist. The
[fragmentation pilot](experiments/exploratory/fragmentation-pilot-v1/README.md)
and [probabilistic forecast pilot](experiments/exploratory/probabilistic-forecast-pilot-v1/README.md)
both recommend closing their bounded expansions on the observed evidence.
Their completed artifacts remain immutable. No final research question or
submission target is established by these exploratory results.

The [exploratory claim map](research/questions/exploratory-claim-map.md) links
the retained observations, negative findings, censoring and repeated data to
the exact pilot artifacts and the remaining topic-selection requirements.
