# External artifact contracts

The study exchanges versioned evidence files with separately maintained
research tooling. This directory contains no copied framework implementation
or placeholder schema. The owning scientific protocol defines acceptance;
the original signed bindings refer to their original monorepo revision.

Do not add a format until a real producer and consumer agree on its invariants,
validation errors and versioning. Restricted bytes and runtime state remain
external. See [`docs/reproducibility.md`](../docs/reproducibility.md).
