# Exploratory claim map

The study needs one navigation artifact connecting both completed pilots to
exact evidence before choosing a research question. The map is a derived,
reviewable Markdown projection under `research/questions/`. It introduces no
new canonical dataset, simulator, decision authority, or runtime dependency.

Each claim identifies the pilot, bounded observation, analysis selector, raw
run and applicable limitations. Source hashes bind the analysis, manifest,
protocol, specification and existing independent review. Negative findings,
right censoring, repeated data and exploratory status remain visible. The map
must not select a theme or infer scientific acceptance from an integrity check.

Verification reopens the nine immutable JSONL objects through the study's
native offline validator, then checks the mapped counters and central decision
criterion against those rows. Forecast summaries can be recalculated without
regenerating ensembles; this check does not independently validate the scoring
algorithm. A fresh isolated review checks claims, denominators, source pointers
and the limits of the verification. Existing README navigation points to the
new map; completed protocols, manifests, analyses and run bytes remain unchanged.

There is no new executable behavior in this slice. Artifact checks and review
are the acceptance checks; synthetic tests of static prose are not introduced.
Any later computational consumer needs its own behavior specification and tests.
