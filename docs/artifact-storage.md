# Artifact storage gate

Status: policy accepted; storage implementation deferred.

Git tracks protocols, metadata, content hashes, lineage, and deliberately public
small artifacts. Large, copyrighted, restricted, or generated bytes require a
durable external artifact root that has not yet been selected.

Until that root and its backup/recovery check exist, acquisition agents may
inspect remote material but may not claim that a downloaded artifact is
canonical or complete. Local `raw/`, `interim/`, `processed/`, and `.runtime/`
paths are disposable caches.

## Promotion gate

An external artifact becomes canonical only when a manifest records:

- logical identity and owning study;
- source and retrieval time;
- licence and access classification;
- byte size and cryptographic content hash;
- durable locator and successful read-back verification;
- backup or independently reproducible recovery path;
- producer, validator, schema version, and supersession lineage.

Secrets and restricted content never enter a manifest, prompt, trace, Git tree,
or public release bundle.
